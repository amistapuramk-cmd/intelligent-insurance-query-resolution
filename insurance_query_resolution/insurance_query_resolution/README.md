# Intelligent Insurance Query Resolution

A simple base project that resolves insurance customer queries using
intent detection, FAQ retrieval, mock policy/claim lookups, and human escalation.

## Setup
    pip install -r requirements.txt

## Run
    python insurance_query_resolver.py

## Try
- What is the status of claim CLM2001?
- When is my premium due for POL1002?
- How do I file a claim?
